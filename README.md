# Dual ta'lim o'quvchilari: bandlik va ish haqi

Dual ta'lim o'quvchilarining dual tashkilotlarda rasmiy ishlashi va ish haqi bo'yicha interaktiv dashboard.

**Sahifa:** https://johnoutsider.github.io/dual-talim-dashboard/

- Davr: 2025-yil iyul – 2026-yil iyun (12 oy)
- Ish haqi mehnatga haq to'lashning eng kam miqdori bilan solishtiriladi: 2025-yil iyulda 1 155 000 so'm, 2025-yil 1-avgustdan 1 271 000 so'm
- Filtrlar: davr, hudud, texnikum, mutaxassislik, jins, yosh guruhi
- Statistik tahlil: tavsifiy statistika, Jini koeffitsienti, Mann–Uitni, Kraskel–Uollis, χ², Spirmen
